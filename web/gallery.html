torque-rs

A game engine library in Rust, based on the Torque Game Engine and Torque3D. These examples run in the browser.

  • Guide
  • API docs
  • GitHub
  • The level demo Walk and jump around a plaza built of cubes.
  • The office A level demo map: desks under ceiling lights, with windows and glass.
  • The valley A level demo map: a lake between mountains, open to the sea at sunset.
  • The arena shooter The box figure with a pistol, in rounds.
  • The vehicle demo Drive a dune buggy around a dirt track over the hills.

The examples need a browser with WebGPU: Chrome or Edge, or Firefox and Safari where WebGPU is turned on. In a browser without it, the page says so and the game does not start.
